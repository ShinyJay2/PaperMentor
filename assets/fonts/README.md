# Bundled report fonts

PaperMentor bundles the fonts used by generated reading reports so users see the intended typography after installing the skill, without relying on remote CSS imports at render time.

## Satoshi

- Source: https://www.fontshare.com/fonts/satoshi
- License: ITF Free Font License, https://www.fontshare.com/licenses/itf-ffl
- Bundled files: `assets/fonts/satoshi/Satoshi-{300,400,500,700,900}.woff2`
- Use: primary Latin/English report font.

## Pretendard

- Source: https://github.com/orioncactus/pretendard
- License: SIL Open Font License 1.1
- Bundled file: `assets/fonts/pretendard/PretendardVariable.woff2`
- Use: Korean report font and CJK fallback.

The repository MIT license applies to PaperMentor code and documentation, not to third-party font files. Keep this notice with redistributed font assets.
