## Visual reading rule

For method/system slides, explain the actual slide figure or diagram when available. If a new aid is needed, generate a separate mono-tone SVG labeled as a PaperMentor conceptual diagram.

## Reading path

1. Map the deck.
2. Explain key slides.
3. Reconstruct missing narration.
4. Connect slide flow.
5. Resolve confusion.
6. Extract final insight.
