# Prerequisite Ladder

Not a template — see `prompts/prerequisite-analyzer.md`.

Write it like a tutor, not a form: list every prerequisite this exact source needs, in order from the most primitive idea (e.g. "what a bit is") up to its notation and key equations; teach each one briefly with a concrete numeric example using real numbers; and tie each back to the paper's symbol, figure, equation, or claim. No fixed sections, tables, or field lists. Stop when the reader can read the target paragraph/equation and restate it in one sentence.
