# Visualization Checklist

- [ ] Visualization is tied to conceptual confusion.
- [ ] Triggered only for relational, sequential, spatial, or dependency-based confusion.
- [ ] Not triggered for a single definition, one symbol, or decorative use.
- [ ] Generated diagram is deterministic mono-tone SVG, not Mermaid.
- [ ] Generated diagram is labeled: "Conceptual diagram generated by PaperMentor. Not a figure from the paper."
- [ ] Question is stated.
- [ ] Concept is stated.
- [ ] Visual encoding is stated.
- [ ] What to observe is stated.
- [ ] Conclusion and limitation are stated.
