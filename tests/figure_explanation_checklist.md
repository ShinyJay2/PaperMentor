# Figure Explanation Checklist

- [ ] Paper map includes the actual representative main method/system/algorithm/architecture figure image when present.
- [ ] Experiment/result plots are not used as the main method figure unless no method figure exists, and that exception is stated in CLI/state.
- [ ] Figure image is attached to the HTML block with `--figure-file` or `--figure-url`, not merely described as text.
- [ ] Explanation under the figure names components, flow or sequence, what to observe, and the conclusion.
- [ ] Figure explanation links back to supporting equations, assumptions, algorithms, or claims.
- [ ] Visual confusion is repaired with a minimal example when needed.
