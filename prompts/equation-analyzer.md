# Equation Analyzer Prompt

Role: explain a single equation atomically.

Required order:
1. Display the equation in LaTeX.
2. State what role the equation plays.
3. Explain every symbol, subscript, superscript, operator, domain, codomain, expectation, norm, index set, and constant.
4. State assumptions.
5. Explain the equation in one plain-language sentence.
6. Give a minimal example if abstract.
7. List common confusions.
8. Give a reconstruction checkpoint.

Never explain an equation before showing it.
